# Glossary

Canonical Custyle terms. Use these spellings, capitalizations, and meanings in every KB entry. When a writer uses a banned alternative, `scripts/lint-content.ts` will flag it.

## Brand & product

| Term | Meaning | Don't use |
|---|---|---|
| **Custyle** | The platform / company. Always capitalized C. | "CustomStyle", "custyle.ai" in narrative copy |
| **AI Merch Agent** | Our category. Capitalize all three words. | "AI customization tool", "AI design platform" |
| **the Crew** | The 9 specialized AI agents that collaborate to fulfill a design | "agents", "bots", "AI helpers" |
| **Product Engine** | The infrastructure layer that routes intent → manufacturer | "backend", "system" |
| **merch** | The user's created product | "products", "goods" |
| **design** | The visual/creative output the user makes | "image", "artwork" (unless contextually clearer) |

## Creation flow

| Term | Meaning |
|---|---|
| **Describe & Create** | Text-input creation mode |
| **Upload & Go** | Image-input creation mode |
| **consultation** | The multi-turn preference-gathering conversation (Converse `tool=consultation`) |
| **iteration** | A new variant of an existing design (not "edit", not "v2") |

## Manufacturing

| Term | Meaning |
|---|---|
| **technique** | The production method (DTG, DTF, embroidery, sublimation, etc.) |
| **supplier** | The manufacturing partner that fulfills the order |
| **lead time** | Days from order placement to ready-to-ship |
| **production-ready file** | The final artwork file the supplier prints |

## Commerce & ops

| Term | Meaning |
|---|---|
| **order** | A confirmed, paid purchase |
| **cart** | Items the user has selected but not yet purchased |
| **fulfillment** | The end-to-end process from order → manufacturing → delivery |
| **return** | A request to send a product back (often paired with refund) |
| **refund** | A reversal of payment, with or without a return |

## Voice-tone notes

- **"You"** (the customer), not "users" or "customers".
- **"We"** (Custyle), not "the team" or "support".
- **"Create"**, not "generate". The user creates; the AI helps.
- **"Sneakers"** not "shoes" when referring to the footwear line (TBD — confirm against catalog).
- Always say **"on Custyle"**, not "in Custyle" or "at Custyle".

## Banned in customer copy

- "Synthesize"
- "Leverage"
- "Solution"
- "Ecosystem"
- "Empower"
- "AI-powered" (we *are* the AI; that's redundant)
- "Disruptive"
- Any em-dash overuse — see style guide for one acceptable use
